# Задание 6. Перегрузка операций

## Задача 10

### Текст задачи

Класс `Triangle` с полями `double a`, `double b`, `double c` (длины сторон треугольника). Реализовать определение класса (поля, свойства, конструкторы, перегрузка метода `ToString()` для вывода полей) и метод: определить, существует ли треугольник с такими длинами сторон. Результат должен быть типа `bool`.

### Алгоритм решения

Класс `Triangle` содержит закрытые поля `_a`, `_b`, `_c` и свойства `A`, `B`, `C` (без автосвойств). В `set` свойств выполняется проверка: сторона должна быть конечным положительным числом, иначе выбрасывается `ArgumentOutOfRangeException`.

Конструкторы:

- без параметров – треугольник со сторонами 1, 1, 1;
- с тремя параметрами – задание сторон;
- копирующий.

Метод `Exists()` проверяет неравенство треугольника: `a + b > c`, `a + c > b`, `b + c > a`. Метод `ToString()` выводит значения полей.

Данные, вводимые пользователем, проверяются на корректность (число, положительное значение, допускается ввод с запятой или точкой).

# Задание 7. Перегрузка операций

## Задача 10

### Текст задачи

В класс `Triangle` добавить перегруженные операции:

Унарные операции:

- `–` – вычисляется площадь треугольника, результатом должно быть вещественное число.

Операции приведения типа:

- `double` (неявная) – результатом является периметр треугольника;
- `bool` (явная) – результатом является `true`, если треугольник с такими длинами сторон существует, и `false` в противном случае.

Бинарные операции:

- `<` – сравниваются площади треугольников;
- `>` – сравниваются площади треугольников.

### Алгоритм решения

- Унарный `-`: если треугольник не существует, возвращается 0. Иначе по формуле Герона вычисляется площадь `S = √(p(p − a)(p − b)(p − c))`, где `p = (a + b + c) / 2`.
- `implicit operator double`: возвращает периметр `a + b + c`.
- `explicit operator bool`: возвращает результат метода `Exists()`.
- Операторы `<` и `>` определены парой и сравнивают значения `-left` и `-right`.

Во всех операторах выполняется проверка аргументов на `null`.
